# Design reference videos

Put the two reference videos here. They are **not committed** (see `.gitignore`); Claude Code reads them locally.

| File | What it's a reference for |
|---|---|
| `landing-reference.mp4` | Look, layout, animation and motion for the new landing page |
| `dashboard-reference.mp4` | Visual style for the existing dashboard (restyle only; no functional changes) |

`frames/` (generated, gitignored) holds stills extracted from the videos so they can be viewed as images.
Use these as references for feel, motion and layout. Don't copy another company's logos, brand marks or text.
