# Echt brand files

| File | Use |
|---|---|
| `echt-mark.svg` | The mark, colour follows the surrounding text (`currentColor`). Use this in the app. |
| `echt-mark-white.svg` | Mark for dark backgrounds (#F4F4F2). |
| `echt-mark-black.svg` | Mark for light backgrounds (#0B0B0C). |
| `echt-favicon.svg` | Favicon / app icon: heavier stroke (26) on a #0B0B0C rounded square. |
| `original/` | The designer's original artwork (reference only). |

Lockup: the mark sits **before** the wordmark "echt" (lowercase, Geist 600, letter-spacing -0.05em). Mark height ≈ the wordmark's x-height to cap height; gap ≈ 0.3 × wordmark size.
Colours: ink #0B0B0C, paper #F4F4F2, signal orange #FF6A2B (accent only).
