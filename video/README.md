# Echt demo video

`echt-demo.mp4` is the 1:47 demo film for Echt (1920×1080, 30 fps, H.264 with voice-over, no music). It walks through the T1 run on [echt-sepia.vercel.app](https://echt-sepia.vercel.app): seven synthetic accounts turn bullish, the agent proposes a practice trade, the Chainlink CRE check (local simulation) finds five linked transfers from one wallet, and the agent does not trade. It then shows T5 (provider fault, REVIEW), T2 (ELIGIBLE), the Etherscan transaction, and Replay (MATCH, then HASH_MISMATCH).

The film is a [HyperFrames](https://hyperframes.heygen.com) project: `index.html` and `compositions/*.html` are generated by `scripts/build.mjs`.

## Rebuild

The raw screen captures and the voice-over are not in git. The scripts regenerate them. Run these from `video/`:

```bash
python scripts/voiceover.py
node scripts/capture.mjs
node scripts/build.mjs
npx hyperframes render --format mov --prores-profile lt -o out/master.mov
ffmpeg -i out/master.mov -c:v libx264 -preset veryfast -crf 18 -pix_fmt yuv420p -movflags +faststart -c:a copy echt-demo.mp4
```

1. `voiceover.py` writes `assets/vo/*.mp3` and word timings (edge-tts, one voice for the whole film).
2. `capture.mjs` records the live site with headless Chrome into `assets/capture/`.
3. Etherscan shows a bot check to headless browsers, so the Etherscan shot is a short screen recording made by hand and cropped to page content. Save it as `assets/capture/etherscan-clip.mp4` (1350×515).
4. `build.mjs` reads the word timings and capture marks and writes the compositions.

Numbers on screen are read from the live page during capture, never typed in. Labels: synthetic accounts, testnet payments, Chainlink CRE local simulation.
